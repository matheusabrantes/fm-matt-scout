## Capture method

The two JPEGs were taken directly from the already-running macOS application with the owner's COR career loaded. The installed renderer/backend files were checked against the current checkout. The PNG is an unchanged copy of the real browser QA capture documented in [QA.md](../QA.md). Player, club, and career records come from the real save.

The native screenshots include macOS window chrome and its capture indicator. The filter image shows the same implemented web interface without native window chrome. The images preserve their captured aspect ratios, show the existing application controls, and link to full-resolution files. No artwork or records were generated for the final images.

The displayed estimates and decoded values retain the [application's coverage limits](../COVERAGE.md). These screenshots are not independent validation of every field or a performance benchmark, and do not show the Football Manager game interface.

The images were inspected for unrelated private material and credentials. They contain player/career details with the owner's permission, local flags, and abbreviated club badges; no player photographs, official club crests, account credentials, local home paths, or server access-token URLs are visible.
